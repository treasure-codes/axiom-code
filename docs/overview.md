# Axiom-Code Overview

Axiom-Code is a semantic static analysis engine designed to transform source code
into structured, prioritized insight.

## What It Does
- Parses code into ASTs and call graphs
- Computes complexity and importance metrics
- Detects architectural and maintainability smells
- Produces ranked summaries and human-readable explanations

## Design Philosophy
- Deterministic first, AI optional
- Insight over noise
- Offline-first developer tooling

## Typical Use
- Onboarding to unfamiliar codebases
- Identifying refactor targets
- Understanding system architecture
